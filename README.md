# Airport-Route-Planner
The assignment is to build an Airport Route Planner in Python using the OpenFlights airports.dat and routes.dat datasets. The program must compute both a minimum-stop route and a shortest-distance route between two IATA airport codes.

## Running the program

1. Install Python 3 on the computer if it is not already installed.
2. Extract the ZIP file and open a terminal in the extracted `Airport-Route-Planner` folder.
3. Run:

```bash
python3 airport-route-planner/main.py
```

On Windows, use `python airport-route-planner/main.py` if `python3` is not available.

The program has no third-party dependencies. Keep the `airport-route-planner/data` folder and both `.dat` files in place when sharing the ZIP file.
