1. Enviroment Setup
- Python3
- No external Libraries
- Only Python Standard Library modules:
+ math
+ csv
+ time
+ os

2. How to run the program:
- Open a terminal and navigate to the project folder: cd airport-route-planner
- Run the program using: python main.python
- Then the program will ask for two IATA airport codes.
- Enter the two IATA airport codes
- After that, the program will display the result
